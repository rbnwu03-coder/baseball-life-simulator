| 名詞                | 定義                        |
| ----------------- | ------------------------- |
| Decision Literacy | 玩家透過選擇、結果與反思，持續提升決策品質的能力。 |
| Narrative Echo    | 一個事件在不同人生階段持續產生新的意義與影響。   |
| Echo              | 世界對玩家選擇留下的回應，可以是短期、中期或長期。 |
| Design Pillar     | 構成《棒球人生》不可替代性的最高設計原則。     |
| Creative Vision   | 整個專案存在的理由，以及希望玩家最終帶走的價值。  |

# UX Sprint 2：少棒第一季 Content & Match Presentation Pass

## 1. 修改前事件盤點

少棒第一季仍是固定八回合；第六回合依 `seasonPosition` 使用四個守位事件之一。第八回合結束後執行既有 `evaluateYouthSeason()`，進入 `youth_season_result`。

| 順序 | 事件 ID | 分類 | Validation | competitionId | 路由 |
|---:|---|---|---|---|---|
| 1 | `youth_season_intro` | 教練／生活 | 否 | — | 固定進入守位輪測 |
| 2 | `youth_position_trial` | 教練測驗／非正式驗證 | 是 | `youth_position_rotation` | 依選項設定主守位；仍固定進入阿哲事件 |
| 3 | `youth_teammate` | 人物事件 | 否 | — | 固定進入紅白賽 |
| 4 | `youth_bench` | 隊內紅白賽 | 是 | `youth_first_intrasquad` | 固定進入正式聯賽 |
| 5 | `youth_match_entry` | 正式聯賽・上場 | 是 | `youth_first_league_game` | 依主守位進入第六回合 |
| 6A | `youth_match_grounder` | 正式聯賽・內野幕 | 是 | `youth_first_league_game` | 固定進入下一次回應 |
| 6B | `youth_match_outfield` | 正式聯賽・外野幕 | 是 | `youth_first_league_game` | 固定進入下一次回應 |
| 6C | `youth_match_catcher` | 正式聯賽・捕手幕 | 是 | `youth_first_league_game` | 固定進入下一次回應 |
| 6D | `youth_match_pitcher` | 正式聯賽・投手幕 | 是 | `youth_first_league_game` | 固定進入下一次回應 |
| 7 | `youth_match_mistake` | 正式聯賽・回應幕 | 是 | `youth_first_league_game` | 固定進入賽後 |
| 8 | `youth_match_after` | 正式聯賽・賽後幕 | 是 | `youth_first_league_game` | 執行既有章節評估 |
| 結算 | `youth_season_result` | 章節結算 | 否 | — | 玩家決定進入位置競爭或重玩 |

`youth_match_entry`、四個守位事件、`youth_match_mistake` 與 `youth_match_after` 都是同一場 `youth_first_league_game`。

## 2. Gameplay 合約

Choice 身分仍由 `eventId + choiceIndex` 決定，選項數量與順序不變。允許修改的只有 `text` 與作為可見結果的 `memory`。

下列欄位被納入修改前快照：

- `effects`
- `flags`
- `skillEffects`
- `positionSkillEffects`
- `positionEffects`
- `setPrimaryPosition`
- `personalityEffects`
- `impressionEffects`
- `relationshipEffects`
- `bodyEffects`

## 4. 結果文字原則

每個修改後結果依序描述：

```text
玩家動作
→ 球或跑者的實際結果
→ 隊友／教練看見的內容
→ 原本數值與關係回饋
```

結果不再只用「留下印象」「增加信心」取代場上發生的事。

## 5. Presentation 整合

- 固定識別縮小，不在每一幕用同等強度重複比賽名稱與目的。
- 局數、出局數、比分與文字壘況集中在「現在」區塊。
- 同一幕只顯示一項最相關能力線索，不再同時排三張能力卡。
- Connector 改為「這一幕要處理」，直接服務選項判斷。
- Timeline 縮小為球季定位，不搶過正文與選項。
- 守位輪測顯示輪次與剩餘球數，不顯示比分。
- 紅白賽使用較柔和的隊內觀察色調；正式聯賽維持比分與勝負感。

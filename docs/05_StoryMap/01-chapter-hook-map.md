## 前三個事件的連續性

```text
看見棒球世界
↓
球場主動把球送到玩家面前
↓
玩家第二天主動決定怎麼再靠近
```

這三個事件形成的基本結構是成立的。

### 優點

* 第一天從觀察自然進入第一次接觸。
* 第二天不是重複，而是把偶然轉成主動選擇。
* 三種人格傾向不是用說明文字決定，而是透過行動逐步形成。
* 家人、球場、電視與公園代表不同的棒球入口。

### 目前風險

* `day1_morning` 的三個選項雖有數值差異，但情節結果仍相近。
* `day2_morning` 的三條路徑最後仍會回到球隊，因此後續必須讓「球場／電視／公園」真的被記住。
* 玩家目前仍沒有清楚的外部目標，例如試訓期限、入隊條件或教練正式邀請。

### 暫時結論

前三個事件不需要刪除，也不需要立刻重寫。

目前應標記為：

| 事件               | 判定          |
| ---------------- | ----------- |
| `day1_morning`   | 必要的氣氛與人格入口  |
| `day1_afternoon` | 第一個核心轉折     |
| `day2_morning`   | 第一次主動選擇棒球道路 |

### 事件 04：`day2_afternoon`－第一次被看見

| 問題       | 分析                                        |
| -------- | ----------------------------------------- |
| 事件目的     | 讓玩家第一次公開表達自己對棒球的興趣，並正式進入教練與其他孩子的視線。       |
| 玩家此刻想要什麼 | 找到一個不會太丟臉、又能繼續靠近球隊的方法。                    |
| 當下阻礙     | 玩家必須在其他孩子與教練面前承認自己的期待，可能暴露自己的不熟練與不確定。     |
| 世界如何回應   | 同齡孩子直接發問，教練則不催促，只等待玩家自己回答。                |
| 選擇是否有差異  | 有。承認興趣偏向直接與勇氣；繼續觀察偏向理解與慢熱；詢問孩子偏向透過關係進入群體。 |
| 是否推動故事   | 有。玩家不再只是自己喜歡，而是第一次讓球場上的人知道自己可能想加入。        |
| 刪除後會失去什麼 | 缺少從私人興趣進入公開承諾的過渡，後續借手套與接受指導會太突然。          |
| 目前功能評價   | 必要事件。                                     |
| 期待值      | 7/10                                      |

#### 初步判斷

這個事件不是大型戲劇轉折，但它完成一項重要變化：

> 玩家第一次讓別人知道自己想靠近棒球。

教練「沒有催，只等待回答」也建立了山本早期的角色特質：

* 不直接替孩子決定；
* 觀察玩家如何學習；
* 給予空間，但不主動降低門檻。

目前的小問題是，三個選項最後都會自然進入下一次傳接球，因此玩家暫時看不出公開回答造成的立即差異。

### 事件 05：`day3_morning`－傳接球的距離

| 問題       | 分析                                    |
| -------- | ------------------------------------- |
| 事件目的     | 讓玩家第一次面對正式棒球動作，並體驗理解與實際完成之間的差距。       |
| 玩家此刻想要什麼 | 接住球，證明自己至少能參與這項練習。                    |
| 當下阻礙     | 球的速度、距離、身體協調，以及被旁人看見失敗的壓力。            |
| 世界如何回應   | 有人借出手套，讓玩家得到真實參與機會，但球不會因為玩家是新手就自動變容易。 |
| 選擇是否有差異  | 有。反應擋球建立直覺；拆解腳步建立基本功；持續要求再一球建立韌性。     |
| 是否推動故事   | 明顯推動。玩家第一次從「碰過球」進入「嘗試學習棒球技術」。         |
| 刪除後會失去什麼 | 少棒入門將缺少第一次能力落差，後續被笑與教練測試都會失去基礎。       |
| 目前功能評價   | 核心事件。                                 |
| 期待值      | 8/10                                  |

#### 初步判斷

這個事件的核心句非常有效：

> 「看懂」和「接住」是兩回事。

它一次完成三件事：

1. 打破玩家前兩天累積的浪漫想像。
2. 建立技術學習的真實難度。
3. 為後續三種類型球員奠定基礎。

三個選項也不是傳統的好、中、壞選項，而是三種合理的學習方式。

### 事件 06：`day3_afternoon`－旁邊的小孩笑了

| 問題       | 分析                                        |
| -------- | ----------------------------------------- |
| 事件目的     | 把單純的技術失敗轉變成具有社交與情緒重量的第一次挫折。               |
| 玩家此刻想要什麼 | 保住尊嚴，不讓一次漏接定義自己。                          |
| 當下阻礙     | 笑聲可能沒有惡意，但玩家無法控制自己如何理解它。                  |
| 世界如何回應   | 球場不只評價能力，也透過其他孩子的反應讓失敗變得公開。               |
| 選擇是否有差異  | 很明顯。忽略笑聲建立韌性與信心；分析失誤建立理解；退回家人身邊建立壓力與安全依附。 |
| 是否推動故事   | 有，而且首次推動玩家的情緒記憶與後續恐懼回收。                   |
| 刪除後會失去什麼 | 第一章會只剩技術學習，缺少「想加入群體卻害怕被評價」的情緒核心。          |
| 目前功能評價   | 核心情緒事件。                                   |
| 期待值      | 8/10                                      |

#### 初步判斷

這是第一章目前最重要的情緒事件之一。

事件的好處在於：

> 笑聲不一定有惡意。

這避免把其他孩子寫成單純壞人，也讓衝突更接近真實童年經驗。真正的壓力不是對方一定在羞辱玩家，而是玩家無法確定：

* 他們是不是在笑我；
* 我是不是不適合這裡；
* 我下一球還要不要繼續。

「先退到家人身邊休息」也不是錯誤答案。它建立了家庭作為安全基地，後期可以回收為：

* 面對失敗時先退開；
* 願不願意向家人承認壓力；
* 成年後是否仍能接受支持。

## 第二組事件的連續性

```text
第一次公開承認興趣
↓
第一次接受真正的技術挑戰
↓
第一次因失敗感受到他人的目光
```

這一組事件形成完整的第一個壓力循環：

```text
期待
↓
嘗試
↓
失敗
↓
情緒回應
```

### 優點

* 壓力不是突然出現，而是由公開承認興趣自然升高。
* 技術失敗與社交壓力彼此連接。
* 三種玩家傾向在每個事件中都有合理的行動方式。
* 家人、教練與同齡孩子開始分別扮演不同功能。
* `day3_afternoon` 留下的情緒，可以在後期比賽失誤時再次回收。

### 目前風險

* `day2_afternoon` 的結果主要仍是數值和旗標，立即回應感稍弱。
* `day3_morning` 與 `day3_afternoon` 都圍繞漏接，連續閱讀時可能感覺同一件事被拆成兩段。
* 「旁邊的小孩笑了」的情緒很強，但笑的孩子目前沒有身分，後續也未必會再次出現。
* 若玩家每次都選擇退縮，第一章仍會順利進入後續，外部代價目前不明顯。

### 暫時結論

這三個事件都應保留。

| 事件               | 判定        |
| ---------------- | --------- |
| `day2_afternoon` | 公開承諾的必要過渡 |
| `day3_morning`   | 第一次正式技術挫折 |
| `day3_afternoon` | 第一個核心情緒事件 |

目前第一章到這裡，已經從「棒球很吸引人」進入：

> 我喜歡它，但我可能不擅長，而且別人會看見。

這是玩家開始真正投入這段人生的地方。

### 事件 07：`day4_morning`－被比較的一天

| 問題       | 分析                                       |
| -------- | ---------------------------------------- |
| 事件目的     | 讓玩家第一次清楚看見同齡差距，理解喜歡棒球不等於自然比別人優秀。         |
| 玩家此刻想要什麼 | 找到面對更強同齡球員的方法，不讓比較直接變成退出理由。              |
| 當下阻礙     | 玩家已開始投入，因此別人的成熟與穩定會直接威脅自我認同。             |
| 世界如何回應   | 球場讓一名同齡孩子以明顯更好的表現出現，沒有安慰，也沒有刻意羞辱玩家。      |
| 選擇是否有差異  | 有。觀察對方建立學習導向；排到對方後面建立競爭導向；回公園玩球則保留自由與樂趣。 |
| 是否推動故事   | 明顯推動。玩家開始決定自己如何理解競爭。                     |
| 刪除後會失去什麼 | 缺少同齡比較帶來的現實感，後續高橋與位置競爭會顯得太突然。            |
| 目前功能評價   | 核心競爭事件。                                  |
| 期待值      | 8/10                                     |

#### 初步判斷

這個事件的重要性很高，因為它第一次提出：

> 喜歡，不代表你比別人厲害。

這句話是整個棒球人生長線的重要母題。

後面所有階段都會反覆遇到類似問題：

* 身體發育比別人慢；
* 同位置有人更成熟；
* 球探更重視另一種工具；
* 新人更年輕、成本更低；
* 傷後恢復速度不如別人。

因此這不是一次性的童年挫折，而是整條生涯競爭邏輯的第一次預告。

目前唯一要注意的是，這名「更強的同齡孩子」還沒有明確身分。若後續高橋就是這個孩子，未來文案可以考慮讓玩家逐步意識到兩者是同一人；若不是，就應避免玩家誤認。

後期推薦信強調「能力以外的部分」，就因此具有前後一致性。

## 第四組事件的連續性

```text

```

這一組事件形成第三個重要循環：

```text

↓

↓

```

### 優點

* 球隊歸屬與個人成長首次形成明確取捨。
* 練習賽不是突然開始，而是先讓玩家選擇是否進場。
* 關鍵球將前面累積的性格傾向轉成具體棒球行動。
* 事件張力逐步升高，沒有直接跳到正式大賽。
* 自由棒球路線仍被保留，而不是強迫所有玩家立即制度化。

### 目前風險

* `day5_afternoon` 的隊友仍多為泛稱，阿哲尚未明確進入玩家記憶。
* `day6_morning` 選擇回公園後，`day6_afternoon` 是否仍發生同一顆練習賽關鍵球，需要確認實際流程是否合理。
* 「只能選一邊」很清楚，但部分玩家可能期待能透過前期能力或關係解鎖第四種折衷方案。
* 三個事件仍延續觀察／直覺／韌性的固定三角，需要留意長期重複感。

### 暫時結論

| 事件               | 判定          |
| ---------------- | ----------- |
| `day5_afternoon` | 第一個核心隊伍關係取捨 |

到這裡，玩家已經不只是「想打棒球的孩子」，而是開始具備三個身分：

* 隊伍裡的人；
* 可能上場的人；
* 必須為下一球做決定的人。

## 三、第一章目前主要問題

### 問題 1：外部目標建立得太晚

玩家前半章主要是在探索興趣與人格，直到後段才逐漸出現「加入球隊」的方向。

因此前幾天的追讀動力主要是：

> 看看下一個小事件。

而不是：

> 我想通過某個明確考驗。

這不代表一定要新增正式試訓，但可以更早暗示：

* 教練正在觀察新孩子；
* 本週結束後會決定是否邀請正式訓練；
* 某一天會有一場簡單評估。

### 問題 2：自由棒球路線與主流程存在矛盾

玩家多次可以選擇：

* 去公園玩球；
* 比較喜歡自由玩球；
* 不急著進入球隊。

但無論如何，下一章都會進入少棒入門。

若後續說明不足，玩家會感到：

> 遊戲允許我拒絕球隊，但其實不接受這個答案。

這條路不一定需要真正分成另一款遊戲，但第二章應該提供一個合理轉換：

* 家人再次帶玩家來看看；
* 教練允許先旁聽或短期試訓；
* 公園夥伴鼓勵玩家去學正式動作；
* 玩家想知道自由玩法和正式訓練有什麼差異。

### 問題 3：三角選項結構重複

許多事件都落在：

```text

直覺／主動
韌性／承擔
```

這套人格建構很清楚，但連續遊玩時可能變成：

> 我每次都在選同一種人格按鈕。

後面修改文案時，不一定要改系統，而是要讓選項更像情境決策，而不是人格測驗。

例如不要只呈現：

* 觀察；
* 直接做；
* 繼續努力。

而是讓每個選項同時包含：

* 當下具體目標；
* 放棄的東西；
* 可能付出的代價。

* 讓借手套的人後來成為阿哲；
* 讓更強的同齡孩子後來被確認是高橋；
* 讓笑聲來源保持模糊，但在後文由某人提起。

如此第一章的事件會和人物線形成更深連結。

第一章內部有不少好事件，但最後的期待是：

這是一種系統回報，不是強烈故事懸念。

更強的章末可望點可以是：

> 教練在名單上留下你的名字，但守位欄仍是空白。

## 本章與第一章的關係

第一章回答：

> 我願不願意繼續靠近棒球？

第二章回答：

> 當棒球開始有正式動作、修正與測驗後，我會成為哪一種新生？

因此第二章不是重複教學，而是第一章人格選擇的第一次正式兌現。

## 本章的主要回報

玩家最後可能形成的類型包括：

* 理解型新生
* 基本功型新生
* 直覺型新生
* 緊張的新生
* 均衡型新生
* 打擊入口型新生

這些類型不能只停留在結果頁名稱，必須在「少棒第一季」中影響：

* 教練第一印象；
* 守位與訓練安排；
* 面對比賽時的優勢與風險；
* 隊友與高橋如何理解玩家；
* 玩家能否把自己的學習方式轉成球隊價值。

## 暫不修改的問題

* 第一章選擇自由棒球的玩家，為什麼會回到正式少棒訓練？
* 本章只有三天正式訓練，是否足以讓玩家相信類型已形成？
* 接球、修正、打擊、測驗的節奏是否太像連續能力測驗？
* `chapter2_team_breath` 是否能有效緩解訓練與評估的作業感？
* 新生類型在下一章是否有足夠明顯的實際差異？
* 結算頁資訊是否讓玩家感到被理解，而不是被系統貼標籤？

#### 初步判斷

這個事件和第一章 `day5_morning` 有清楚的承接。

第一章山本說：

> 先讓我看看你怎麼學。

這一章則真的開始檢查：

> 當你被指出錯誤時，你會怎麼學？

因此它不是單純的技能加點事件，而是山本判斷玩家是否值得持續投資的第一次實證。

三個選項的差異也很合理：

* 重做十次：願意承受重複與修正。
* 追問慢在哪裡：主動理解問題。
* 用下一球證明：把修正變成表現壓力。

第三個選項不是錯誤答案，但它會留下焦躁、壓力與不穩定，這和後期山本對玩家「能力夠不夠」與「大家敢不敢把下一球交給你」的評價能形成長線呼應。

### 問題 1：訓練場景重複度偏高

本章有三個主要場景都圍繞接傳球：

### 問題 2：新生類型可能太像人格測驗答案

玩家已經多次選擇：

* 先觀察；
* 先求穩定；
* 直接嘗試；
* 願意重做；
* 急著證明。

如果類型判定只是累計相似選項，玩家可能很快理解：

> 我只要一直選觀察，就會拿到理解型新生。

這不一定是壞事，但會降低情境決策感。

更理想的狀態是：

* 同樣偏觀察的玩家，也可能因為怕失誤而成為緊張型；
* 直覺型玩家若願意接受修正，能形成不同變體；
* 基本功型玩家若打擊事件表現突出，能出現混合型結果。

### 問題 3：測驗的實際利害關係仍不夠具體

玩家知道教練會評估自己，但不清楚這次評估會直接改變：

* 守位安排；
* 訓練組；
* 上場順位；
* 是否能進入正式球季。

因此測驗目前比較像類型判定，而不是命運節點。

下一章確實會根據新生類型改變開場，但玩家在測驗當下未必感受到這個利害關係。

---

### 問題 4：阿哲與高橋仍未正式成形

第二章已經開始談：

* 隊伍；
* 其他孩子；
* 公開測驗；
* 練習後收球。

但人物仍多是泛稱。

這使第二章有球隊感，卻還沒有明確人際記憶點。

阿哲和高橋不一定要立刻完整登場，但至少可以考慮：

* 阿哲是最早邀玩家一起收球的人；
* 高橋是測驗中動作最成熟的孩子；
* 玩家在結算前第一次記住兩個名字。

### 問題 5：章末期待主要依賴系統回報

第二章的章末期待是：

所以章末仍偏向「看類型如何運作」，而不是「我一定要知道下一個結果」。

## 本章主要人物功能

### 山本教練

本章中的山本開始從「觀察玩家怎麼學」轉向：

> 判斷是否能把正式任務交給玩家。

他的核心評價不再只是天賦，而是：

* 是否可靠；

### 阿哲

他的主要功能是：

* 讓玩家看見教練沒有注意到的失誤；

### 高橋

高橋第一次以「比玩家更成熟、先占據位置的人」出現。

他的主要功能是：

* 把抽象比較轉成具體對手；
* 讓坐板凳不只是沒有上場，而是看見某人站在自己想守的位置；

這種選擇非常符合真實競技環境，也能合理建立阿哲的疏遠與玩家的野心。

## 守位分支整體判斷

四種守位已經不是換皮事件。

它們分別要求玩家理解不同責任：

```text id="sd92yf"
內野手：在極短時間裡選擇出局方式
外野手：在大空間裡先判斷路線與身後
捕手：同時處理投手、打者、跑者與守備
投手：從每一球開始承擔控制與失控
```

這是目前遊戲蜘蛛網架構中非常成功的部分。

因為守位不只改變數值，也改變：

* 情境；
* 用語；
* 決策；
* 失敗方式；
* 被球隊使用的價值。

## 目前共同問題

### 1. 選項成功率偏高

四條路線大多數選項都能完成正面結果，只有少數冒險選項留下明顯失誤。

這對第一次少棒上場是合理的，不宜過度懲罰，但也可能讓玩家感覺：

> 無論怎麼選，我都會完成任務。

### 2. 新生類型主要提供提示，較少改變結果

內野事件會依新生類型給出不同的內在文字，但真正可選內容與結果基本相同。

因此目前類型的作用偏向：

> 我用不同方式理解同一球。

還沒有完全達到：

> 我的類型讓我在某種球上有不同能力或風險。

### 3. 捕手路線最像完整人物戲

捕手事件不只處理技能，也處理投手信任與場上指揮。

其他位置較偏技術事件。

這不是一定要修正，但後續可讓：

* 內野增加與游擊手的協作；
* 外野增加與中外野手的喊聲；
* 投手增加與捕手的暗號信任。

如此四條路線都能同時具備人物關係。

### 4. 高橋與阿哲暫時退到場外

守位事件本身很完整，但前面剛建立的阿哲與高橋，在這一球裡大多沒有明確存在。

可以考慮由既有人物承擔部分場上聲音，例如：

* 阿哲喊補位；
* 高橋站在相鄰守位；
* 捕手或投手是其中一人；
* 賽後由他們回應玩家處理。

這能讓守位分支與人物線更緊密。

## 三、第三章目前主要問題

### 問題 1：玩家幾乎一定會取得正式上場

* 新生評估；
* 教練信任；
* 板凳等待；
* 隊友與競爭選擇。

但流程最終仍固定進入 `youth_match_entry`。

這會稍微削弱：

> 我是否真的爭取到這次機會？

後續可考慮讓低信任玩家仍然上場，但任務更小或理由不同，例如：

* 臨時補位；
* 大比分時段；
* 代跑或守備一局；
* 主力受傷後被迫上場。

如此不必阻止玩家體驗內容，也能讓世界更誠實地回應前期累積。

### 問題 2：守位專屬事件成功度略高

四種守位的大多數選擇都能完成正面結果。

尤其：

* 內野理解選項幾乎是最佳答案；
* 投手三個選項大多取得出局；
* 外野前兩個選項都成功接球；
* 捕手即使被安打，也保留關係價值。

後續不必提高隨機懲罰，而是讓不同選擇承擔不同代價：

* 跑者推進；
* 用球數；
* 體力；
* 隊友信任；
* 下一球難度；

```text
我取得了初步位置

↓
```

## 本章與第三章的關係

第三章回答：

> 球隊願不願意第一次把任務交給我？

第四章回答：

> 在所有人都開始爭取同一個位置後，我能不能讓這份信任持續？

因此這一章不是再次測驗能力，而是把第三章累積的關係與印象真正轉換成競爭環境。

## 本章最重要的結構變化

前三章大多數玩家會經歷相同主事件，只在文字、數值或守位事件上產生差異。

第四章開始出現：

> 不同玩家可能根本不會看到同一個人物事件。

例如玩家可能遇到：

* 山本私下留下額外訓練；
* 山本交出分組名單，讓玩家帶隊；
* 山本因玩家情緒不成熟而扣住下一顆球；
* 高橋主動邀請共同特訓；
* 阿哲願意留下陪練；
* 或練習後根本沒有人留下。

這表示人物關係首次改變了事件選單本身，而不只是改變台詞。

## 本章主要人物功能

### 山本

山本在本章不只判斷能力，而是依玩家過往行為形成不同評價：

* 可靠；
* 有企圖心；
* 能領導；
* 情緒不成熟；
* 值得額外投資；
* 或仍待觀察。

他的功能開始從教基本動作轉為：

> 決定要把多少時間、信任與責任投資在玩家身上。

### 阿哲

阿哲在本章可能形成三種主要狀態：

* 高信任：願意說出怕被淘汰與害怕拖累隊伍。
* 中度關係：仍停留在球場同伴，可能變近也可能變遠。
* 低關係：沉默與分工問題已經真正影響場上補位。

他的功能是檢查：

> 玩家是否能在競爭中維持關係，以及幫助是否逐漸變成依賴。

### 高橋

高橋在本章可能從單純競爭者進一步成為：

* 直接挑戰的對手；
* 承認玩家的競爭者；
* 共同訓練的夥伴；
* 或仍只比較結果的宿敵。

他的功能是檢查：

> 玩家如何定義競爭：只想贏，還是能利用對手讓彼此變強。

## 本章主要回報

玩家在本章結束時會得到：

* 先發或板凳結果；
* 明確位置競爭評價；
* 山本對自己的核心印象；
* 阿哲目前的關係弧線；
* 高橋目前的競爭弧線；
* 對替補、先發與球員身分的理解；
* 進入青少棒前的最後少棒定位。

## 暫不修改的問題

* 關係分支很多，但玩家是否能清楚理解自己為何進入某個事件？
* 部分高品質人物事件只有特定數值才能看到，是否容易被多數玩家錯過？
* 阿哲高信任路線是否容易走向過度依賴，而善意選項反而成為隱性風險？
* 高橋的夥伴與宿敵路線是否有足夠不同的後續兌現？
* 山本的額外訓練、領導、警告與無特別關照是否平衡？
* 先發測試是否真的整合前面的人物與訓練結果，還是最後仍由單次評價決定？
* 玩家落選先發時，是否仍有足夠動力進入青少棒？
* 捕手測驗比其他守位有獨立事件，其他守位是否因此略顯泛化？
* 本章資訊與關係狀態較複雜，玩家是否能從 UI 看出人物如何理解自己？

#### 初步判斷

這個事件成功把第三章的回報反轉成新的問題。

第三章告訴玩家：

> 你取得了初步位置。

第四章立即補上一句：

> 但名字後面還有一個問號。

這個問號是很有效的視覺鉤子，因為它同時代表：

* 教練仍未完全信任；
* 高橋仍可能取代玩家；
* 第一次上場不等於穩定角色；
* 過去的好表現只能換到下一輪觀察。

> 「位置不是獎品。誰能讓球隊放心，誰就留在那裡。」

這句把競爭標準從能力高低提升成「可交付性」。

選項也分別把玩家帶向三條人物線：

* 對自己：把問號當機會。
* 對高橋：研究他為何領先。
* 對阿哲：先確認彼此位置與分組。

因此本章一開始就不是單純練能力，而是在決定玩家要如何進入競爭。

#### 初步判斷

這個事件的功能非常重要，因為它刻意寫了一個「普通星期三」。

標題與開場都在說：

> 真正消耗人的，不一定是決勝測驗，而是沒有人會記得的重複訓練。

這使位置競爭不只是戲劇節點，而有日常重量。

三個選項也形成很實際的資源取捨：

#### 記錄失誤原因

玩家增加理解與基本功，但多消耗恢復時間。

#### 和高橋提高難度

玩家讓練習更接近比賽，也同步提高競爭壓力與疲勞。

#### 陪阿哲完成弱項

玩家犧牲自己的部分球數，換取隊形與關係成長，但甚至可能降低教練信任。

最後一點值得注意。

幫助阿哲並不是純粹善意最優解，而可能讓教練認為玩家沒有充分使用個人競爭時間。這讓關係選擇開始具有真實成本。

## 分支整體優點

* 人物關係真的改變玩家會看到的事件。
* 正面與負面印象都有具體世界回應。
* 教練、高橋、阿哲提供不同種類的資源。
* 沒有關係的玩家也有合理內容，不會出現劇情空洞。
* 分支不是單純獎勵，而是在提出不同責任。

## 目前主要風險

### 1. 分支敘事強度不完全等值

`echo_coach_leadership` 與 `echo_rival_respect` 都有明確人物弧線轉折。

相比之下，`echo_teammate` 和 `echo_solo` 比較像生活片段。

這不代表每條都必須一樣戲劇化，但不同玩家可能感受到本章品質差距。

### 2. 玩家不一定知道為何進入該事件

程式依照：

* 教練印象；
* 高橋敬意；
* 教練信任；
* 隊友連結；
* 宿敵競爭；

依優先順序決定事件。

如果 UI 沒有清楚呈現人物對玩家的印象，玩家可能只覺得事件隨機出現。

### 3. 高品質事件可能互相排斥

玩家可能同時擁有：

* 高教練信任；
* 高阿哲連結；
* 高高橋競爭。

但本輪只會看到其中一個事件。

這是必要的分支取捨，但需確認後續還有機會兌現其他關係，不然玩家累積的部分關係可能暫時消失。

### 4. 優先條件可能偏向教練線

事件判斷中，教練不成熟、教練領導、高橋敬意、教練信任、阿哲關係、高橋競爭依序檢查。

因此部分玩家即使阿哲關係很高，也可能先被山本事件截走。

後續需要檢查整章是否還有阿哲專屬事件補回；目前下一階段確實有 `azhe_bond_high／mid／low`，所以結構上仍成立。

## 暫時結論

這一組分支是目前蜘蛛網架構最成功的部分之一。

因為玩家過去的選擇已經不只是：

* 改一段文字；
* 加一個數值；
* 顯示不同評語。

而是直接決定：

> 這個星期，究竟是誰願意留下來陪你，以及他為什麼願意。

### `azhe_bond_high`－阿哲只對你說的事

| 問題       | 分析                                                 |

#### 初步判斷

這個事件的品質很高，因為它不是單純的「朋友找你談心」。

阿哲說的是：

> 我怕自己拖累隊伍。

這和整章的先發競爭直接相連，也符合他前面「教練沒看見的失誤」所建立的脆弱。

四個選項代表四種完全不同的關係倫理。

#### 坐在旁邊，等他自己把話說完

玩家沒有把情緒立刻變成訓練問題。

這會讓阿哲感受到：

> 我不需要先被修好，才值得被理解。

這是最成熟的信任型回應，也會讓阿哲保有自己的判斷能力。

#### 設計提醒暗號

玩家把恐懼轉成場上合作方法。

短期看起來非常有效，但阿哲可能開始在每個不確定局面先看向玩家，逐漸形成依賴。

這是一個很好的設計，因為善意不是免費正解。

#### 說大家都會怕，別想太大

玩家試圖降低壓力，但實際上淡化了阿哲的感受。

阿哲不會立刻翻臉，只是下一次不再說。

這種關係降溫比直接衝突更真實。

#### 提醒明天仍是競爭

玩家建立清楚界線，但也讓阿哲理解：

> 這個人不會在競爭之外持續接住我。

這會自然走向疏遠。

* 沒有人喊球；
* 兩人都以為對方會處理；
* 球從兩副手套之間穿過；
* 教練吹停練習；

這是成熟且現實的中間解。

玩家維持自己的解釋，但代價是阿哲不再提醒，教練信任也下降。

這讓責任推卸有具體後果。

| `azhe_bond_mid`  | 中度關係 | 是否讓普通隊友情繼續靠近 | 暫無直接比賽後果         |  8/10 |
| `azhe_bond_low`  | 疏遠   | 是否修復已影響守備的關係 | 補位失誤、喊聲消失、教練信任變化 | 10/10 |

## 三條分支的整體優點

* 高、中、低關係不是同一事件換台詞，而是不同類型的情境。
* 高信任不等於全是獎勵，存在過度依賴風險。
* 中度關係保留真實的人際灰區。
* 低關係會直接影響球場合作與球隊價值。
* 玩家可以修復場上合作，而不必強迫恢復親密。
* 每條分支都能自然延伸到青少棒的補位與阿哲退隊事件。

## 目前主要風險

### 1. 高信任路線可能把善意導向依賴

若玩家多次選擇幫助阿哲，容易累積：

* `trusts`
* `depends`
* 私人暗號
* 阿哲等待玩家決定

這是有意義的風險，但遊戲必須讓玩家理解：

> 幫助沒有錯，問題是有沒有保留阿哲自己判斷的空間。

否則玩家可能覺得自己一直選善意，卻被系統懲罰。

### 2. 中度路線敘事回報較弱

高信任有談心，低關係有場上失誤，中度關係只有一瓶水。

這符合真實感，但從遊戲追讀角度，中度玩家可能感覺內容較平。

後續可以透過更細緻的累積回報補強，而不一定要增加戲劇衝突。

### 3. 低關係事件可能非常容易被理解

玩家會清楚知道：

> 關係差造成補位失誤。

相比之下，高信任造成依賴的風險較隱晦。

這種不對稱本身合理，但後續需要讓依賴路線也產生可見的場上代價，例如阿哲在關鍵球前總先看玩家，導致兩人都慢半步。

### 4. 阿哲線與位置競爭主線結合度很高

這是優點，也可能造成阿哲線比其他人物更有情緒重量。

高橋主要處理競爭，山本主要處理評價，阿哲同時涉及：

* 信任；
* 依賴；
* 疏遠；
* 場上合作；
* 退隊；
* 棒球身分轉換。

後續需確認高橋與山本也有相近深度的長期人物轉折。

| 目前功能評價   | 核心身分定義事件。                                                |

#### 初步判斷

這個事件是第四章的重要轉折，因為問題不再是：

> 我能不能贏過高橋？

而是：

> 如果現在還贏不了，我是否仍然知道自己為什麼是球員？

阿哲負責把問題直接說出口：

> 如果不是先發，你還算球員嗎？

高橋則在旁邊整理手套，沒有介入，卻形成另一層壓力：

> 你的競爭者正在聽你如何定義競爭。

山本沒有參與也很合理。這不是教練能替玩家回答的問題。

---

#### 選項一：先把替補能做的任務做到最好

這個選項不是放棄先發，而是把目前角色轉換成具體任務。

它會建立：

* 教練可靠印象；
* 阿哲信任；
* 隊友關係；
* 責任與善意人格。

核心價值是：

> 身分可以暫時不是先發，但任務仍然可以被完成。

這是一條成熟而穩定的球隊型路線。

目前需要注意的是，這個選項同時增加多種正向資源，可能被玩家辨識為安全且高收益的最佳答案。

---

#### 選項二：我會繼續競爭，直到成為先發

這個選項保留先發企圖，但沒有貶低替補。

它會加深：

* 高橋競爭；
* 高橋敬意；
* 教練對玩家競爭性的印象；
* 野心與勇氣。

這是最直接的競技型回答。

它的優點是沒有把野心寫成負面人格，而是承認：

> 想成為先發，本來就是合理目標。

高橋因此更可能把玩家視為真正對手。

---

#### 選項三：我還不知道，但不想因名單討厭棒球

這是四個選項中最具內在界線的一個。

玩家沒有提出位置策略，而是先保護：

* 對棒球的喜愛；
* 競爭之外的自我；
* 長期投入的心理空間。

它會降低耗竭風險，也形成較思考型、情緒型的人格方向。

這個選項對後期成年篇尤其重要，因為它能自然連到：

> 當球員身分不再穩定時，我是否仍然願意留在棒球裡？

目前它的短期回報不如其他選項具體，但長期敘事價值很高。

---

#### 選項四：守位排不到，就先靠棒子進打線

這個選項回收第二章建立的「打擊入口」。

玩家不是放棄守備，而是重新定義進入先發的方式：

> 守位競爭不順，就先讓球隊需要我的打席。

它會增加：

* 打擊能力；
* 野心；
* 教練競爭印象；
* 高橋競爭；
* 疲勞與固執傾向。

這是很成功的蜘蛛網回收，因為前面看似次要的打擊事件，現在真正成為替代路徑。

核心問題是：

##### 投手

> 打者已連續碰掉三球，手臂也開始發沉。

核心問題是：

* 疲勞；
* 配球調整；
* 是否仍能執行捕手暗號。

程式中雖然也準備了捕手版本文字，但實際流程會讓捕手進入獨立的 `competition_catcher_test`，因此這裡的捕手情境目前應視為備用文字，而不是正常可到達內容。

主要回報是：

* 教練信任提高；
* 比賽表現提高；
* 守位基本能力提高。

這是一條可靠型選擇。

#### 選項二：依照觀察即時調整

玩家根據局面改變原先計畫。

主要回報是：

* 球商；
* 反應或守位適應能力；
* 少量教練信任；

因此兩者差異主要存在於：

* 技能成長；
* 教練評價；
* 玩家自我敘事。

實際結果差距仍不明顯。

玩家使用非制式但熟悉的方式處理。

主要回報是：

* 高橋敬意；
* 直覺；
* 比賽表現。

這個設計很有意義，因為前兩個選項主要被教練理解，第三個則主要被競爭者理解。

它代表：

> 教練看的是可預期性，高橋看的是你有沒有自己的武器。

但目前三個選項的比賽表現全部相同，直覺選項也沒有額外失敗或壓力代價。

因此選項敘事差異大於結果差異。

> 投手反覆摸帽沿，不確定玩家的暗號是否可信。

它不是最華麗，但最能讓教練放心。

---

#### 選項二：提前讀出低球，擋球後立刻指揮補位

玩家不只完成擋球，也立即喊出三壘補位。

* 擋球；
* 配球與指揮；
* 球商；
* 教練信任；
* 隊友連結；
* 最高比賽表現。

這是捕手事件中最完整的答案。

它同時完成：

* 技術；
* 預判；
* 聲音；
* 守備協調；
* 跑者控制。

目前風險也很明顯：它在數值與敘事上幾乎全面優於其他選項，容易成為標準正解。

---

玩家不把暴投只當成技術錯誤，而是先處理投手狀態。

主要回報是：

* 配球與指揮；
* 球商；
* 隊友關係；
* 教練信任；
* 比賽表現。

這個選項不一定立即解決三壘跑者威脅，卻建立：

> 投手願意在下一球完全照捕手節奏出手。

它代表較長期的捕手價值。

但事件當下跑者已經起跑，玩家卻先處理下一球暗號，時間順序稍微模糊。

後續審稿時需要確認：

* 玩家是否已經先擋住這顆球；
* 跑者最後是否被阻止；
* 何時走上投手丘；
* 為什麼此時仍有機會改變下一球暗號。

目前敘事意義成立，但場上連續動作需要再寫清楚。

## 目前主要不平衡

### 1. 捕手測驗明顯更完整

捕手路線包含：

* 比數局面；
* 跑者；
* 打者習慣；
* 投手心理；
* 關係條件；
* 擋球；
* 指揮；
* 下一球安排。

一般守位測驗雖有守位差異，但最後仍共用同一組選項與結果結構。

因此捕手玩家會感受到：

> 我的守位真正改變了整段事件。

其他守位玩家則比較像：

> 守位改變開場文字，但核心選擇仍相同。

### 2. 一般守位三個選項結果過於接近

三個選項全部提供：

```text
performance +2
```

主要差異只是：

* 教練信任；
* 球商與守位技能；
* 高橋敬意。

這使玩家較難感受到場上結果真的不同。

後續可考慮讓不同選項改變：

* 是否完成出局；
* 跑者是否推進；
* 體力消耗；
* 下一球難度；
* 教練是否調整站位；
* 高橋是否改變挑戰方式。

### 3. 捕手第二選項接近全面最佳解

「預讀低球並指揮補位」同時得到：

* 最高表現；
* 高教練信任；
* 隊友連結；
* 多項技能。

另外兩個選項則主要代表不同價值取向。

如果第二選項沒有前置條件、失敗風險或較高壓力成本，玩家很容易把它辨識成最優選項。

### 4. 捕手第三選項的動作時間需要釐清

目前敘事容易被理解成：

> 跑者已起跑、球已落地，但玩家先去處理投手心理。

需要補清楚玩家已經完成這一球的最低限度處理，再走上投手丘安排下一球。

這是文案連續性問題，不是事件結構問題。

# 三個事件的連續性

```text
玩家先回答如何理解先發與替補
↓
進入最後一球的位置測驗
↓
依守位證明自己如何處理壓力
↓
累積最終先發測試前的人物與能力評價
```

這段結構的優點是：

> 先回答我是怎樣的球員，再用一顆球證明這個答案。

例如：

* 說要做好替補任務的玩家，可以選擇穩定處理。
* 宣告要成為先發的玩家，可以使用直覺或高風險方法。
* 想保護棒球熱情的玩家，可以不把這一球視為身分審判。
* 想靠打擊進入打線的玩家，即使守位測驗普通，也仍保留另一條路。

## 整體優點

* `competition_role_talk` 把名單問題提升成球員身分問題。
* 打擊入口在第四章獲得實際回收。
* 一般守位測驗會依位置改變具體局面。
* 捕手路線真正整合過往隊友關係。
* 教練、高橋與隊友分別理解不同選擇。
* 最終先發測試前，玩家已經完成心理與技術兩層準備。

## 目前主要風險

* 身分對話的四個選項長期價值很好，但短期回報並不完全平衡。
* 一般守位測驗共用選項，分支深度低於捕手。
* 一般測驗三個選項的場上結果幾乎相同。
* 捕手第二選項過度接近標準正解。
* 捕手第三選項的動作時序需要修正文案。
* `competition_position_test` 中保留了正常流程不會使用的捕手文字，容易增加維護混亂。

這一段最重要的成果是：

> 玩家不只在爭一個先發名額，也開始決定自己是否能在沒有先發時仍然保有球員身分，以及要用哪一種價值讓球隊繼續需要自己。

### 事件 05：`starter_selection_test`－倒數結束：先發守位測試

| 問題       | 分析                                       |
| -------- | ---------------------------------------- |
| 事件目的     | 將整章累積的訓練、教練信任、人物關係與位置表現，收束成最後五球的先發競爭。    |
| 玩家此刻想要什麼 | 讓自己的最終評價超過競爭者，進入下一場比賽的先發候選。              |
| 當下阻礙     | 玩家已知道雙方目前評價；最後只剩五球，任何失誤都可能被放大，也沒有時間重新調整。 |
| 世界如何回應   | 山本公開雙方評價，並把標準定義成「誰能讓我把下一場第一局交出去」。        |
| 選擇是否有差異  | 有。五球求穩偏可靠；逐球調整偏理解與臨場判斷；最快動作偏搶眼、競爭與高風險。   |
| 是否推動故事   | 非常明顯。這是整個位置競爭章的最終技術判定。                   |
| 刪除後會失去什麼 | 前面的訓練與人物分支會直接跳到名單結果，玩家缺少親手完成最後測驗的參與感。    |
| 目前功能評價   | 核心先發決勝事件。                                |
| 期待值      | 9/10                                     |

#### 初步判斷

這個事件的核心標準非常清楚：

> 今天不是看誰做出最漂亮的一球，而是看誰能讓我把下一場的第一局交出去。

這句成功回收第四章的核心母題：

* 位置不是獎品；
* 一次好球不等於可靠；
* 教練真正選擇的是可交付性；
* 先發代表球隊願意從第一局就承擔使用你的風險。

玩家也會在選擇前看到：

* 競爭者目前評價；
* 自己目前評價；
* 最後五球將決定的結果。

這讓前面累積的數值第一次被轉成可理解的競爭資訊。

---

#### 選項一：降低難度，五球都先求確實完成

玩家主動放棄搶眼表現，以可預期性換取教練信任。

主要回報包括：

* 紀律；
* 壓力降低；
* 接球能力；
* 教練信任。

這是最符合山本評選標準的選項。

它回答的是：

> 在只剩五球時，我是否願意先讓教練知道每一球會得到什麼結果？

目前風險是這個選項直接增加兩點教練信任，又降低壓力，很可能成為最安全的先發解。

如果最終評分高度依賴教練信任，它可能不只是穩健選項，而是數值上的最佳答案。

---

#### 選項二：依打者與彈跳逐球調整站位

玩家願意承擔判斷失誤的風險，換取更貼近實戰的處理。

主要回報包括：

* 觀察；
* 球商；
* 反應；
* 教練信任。

這是一條理解型與臨場型路線。

它的價值不是每一球都使用同一答案，而是：

> 五球之間能不能根據新資訊改變自己？

這比固定求穩更能證明玩家具備比賽閱讀能力。

但目前程式效果沒有直接寫出判斷錯誤的實際風險，只有增加壓力。因此文案中的風險大於系統代價。

---

#### 選項三：用最快動作正面壓過競爭者

玩家不再只滿足於完成，而是試圖在最後五球留下最醒目的差距。

主要回報包括：

* 自信；
* 壓力；
* 傳球；
* 反應；
* 宿敵競爭；
* 疲勞。

這條路線主要被高橋理解，而不是被教練直接信任。

它回答的是：

> 我是否願意用自己的武器，直接在競爭者面前拉開差距？

選項的風險描述成立：

> 一次失手可能放大代價。

但目前效果主要增加疲勞與壓力，沒有明確的測驗失敗代價。因此它仍可能成為能力成長較多、實際風險有限的進攻型選項。

#### 初步判斷

這個事件是第四章完成度最高的部分之一。

它沒有只顯示：

```text id="bhz3mc"
你成為先發
```

或：

```text id="tqsjv8"
你繼續坐板凳
```

而是讓同一張名單同時被四個角度理解：

* 玩家自己的過往；
* 高橋的競爭；
* 阿哲的關係；
* 山本的評價。

事件最後的總結非常準確：

> 同一張名單讓三個人用不同方式看見你如何面對輸贏。

這就是人物蜘蛛網開始成立的證據。

## 過往記憶回響

結果頁會依玩家早期經驗顯示不同回收。

### 曾經怕失誤

玩家會想起自己以前習慣先看別人怎麼做，但現在已經能在被注視時完成動作。

這條回響表達的是：

> 早期恐懼沒有消失，但玩家已經具備新的行動方式。

### 曾經喜歡加練

玩家會看見沒有人記錄的練習確實換到評價，同時也留下疲勞。

這條回響不是單純稱讚努力，而是保留：

> 加練有效，也有身體成本。

### 其他路線

教練看的不只是最後五球，也包括：

* 此前怎麼練；
* 怎麼和隊友相處。

這句能提醒玩家最終名單不是單次考試。

## 高橋的結果回應

高橋的台詞會依玩家輸贏與最後測驗方式改變。

### 玩家獲勝且選擇進攻型測驗

高橋會問：

> 那種球，你能每次都做嗎？

這不是否定玩家，而是指出：

* 一次壓過對手不等於長期穩定；
* 搶眼動作必須能被重複；
* 競爭不會在名單公布時結束。

### 玩家以其他方式獲勝

高橋把下一顆球丟進玩家手套：

> 明天照樣比。

這是非常好的宿敵回應。

他承認目前結果，但不把它變成永久勝負。

### 玩家落選

高橋不慶祝，而是指出玩家測驗中最好的一球：

> 那球不是運氣。別把其他球也當成運氣。

這使高橋不只是贏家，而是看得懂玩家能力的人。

這條落選回應甚至可能比獲勝回應更有推進力，因為它給玩家一個可追趕的具體理由。

## 阿哲的結果回應

### 關係疏遠

阿哲看見玩家表情，但最後沒有走過來。

這個結果很克制。

他不是嘲笑，也不是報復，只是認為自己不再是適合靠近的人。

### 高信任

阿哲先問的不是有沒有先發，而是：

> 你現在想不想說話？

這成功回收玩家過去如何對待阿哲的脆弱。

現在角色位置交換：

* 過去是阿哲把害怕交給玩家；
* 現在是阿哲詢問玩家是否需要被接住。

這是很完整的關係回報。

### 一般關係

阿哲站在名單旁，等待玩家如何面對結果。

他沒有過度介入，也沒有消失，符合中度關係的距離。

## 山本的結果回應

### 情緒不成熟印象較高

山本先要求玩家：

> 把情緒留到所有人看完名單之後。

這代表他仍然不完全信任玩家在公開環境中的反應。

這不是再次責罵，而是延續先前「沒有立刻給球」的矯正方式。

### 可靠印象較高

山本直接把下一場守備任務交给玩家，不重新解釋。

這是很有力量的信任回報。

真正的教練信任不一定是一段稱讚，而可能只是：

> 他認為你已經知道該怎麼做。

### 一般狀態

山本提醒：

> 名單評的是現在，不是身分。

這句能避免玩家把先發或板凳變成永久人格判決。

## 名單公布後的三個選擇

### 收起名單，回到下一次練習

這個選項不追問、不慶祝，也不逃離。

玩家接受目前位置，再回到長期循環。

它主要建立韌性，也讓三個人物記住玩家看到結果後的第一個動作。

這是最中性的成熟收束。

### 先找教練確認下一個考核標準

玩家不只問：

> 為什麼不是我？

而是詢問：

> 下一次要證明什麼？

這會增加：

* 教練信任；
* 山本對玩家可靠的印象；
* 高橋對玩家的敬意。

高橋留在旁邊聽完也很重要。

這表示玩家獲得的資訊可能同時成為競爭者的資訊，沒有免費的秘密優勢。

### 去找高橋約下一組傳接球

玩家選擇名單公布後立刻延續競爭。

這會增加：

* 高橋敬意；
* 高橋競爭；
* 疲勞；
* 阿哲距離。

最後一項是很好的關係代價。

玩家沒有做錯，但阿哲看見：

> 名單公布後，玩家第一個走向的人是高橋。

關係因此發生細微偏移。

# 第四章完整診斷

## 一、章節結構

第四章目前形成以下完整弧線：

```text id="fas6bi"
第二輪名單出現問號
↓
普通訓練中分配有限時間
↓
依過往印象進入不同人物回響
↓
阿哲關係形成信任、依賴、中度關係或疏遠
↓
玩家回答先發與球員身分的關係
↓
進入一般守位或捕手專屬測驗
↓
最後五球決定先發候選
↓
山本、阿哲、高橋共同回應結果
↓
帶著位置與人物關係進入青少棒
```

這是一個完整的蜘蛛網章節。

前半段由過往選擇決定玩家看見誰；後半段再把不同路線收回共同的先發測驗與名單結果。

## 三、第四章最成功的設計

### 1. 關係真正改變事件內容

玩家不是只看到不同一句話，而是可能根本進入不同場景。

這表示關係系統已從：

```text id="8apuh6"
數值
```

升級成：

```text id="ie30v5"
事件選擇權
```

玩家過去如何對待人物，會決定現在誰願意留下。

---

### 2. 正面關係也存在責任與風險

阿哲高信任可能走向依賴。

高橋尊重可能要求玩家分享弱點。

山本信任可能變成領導整組人的責任。

因此高關係不是單純獎勵，而是：

> 人物把更重要的東西交給玩家後，玩家如何承擔。

---

### 3. 負面印象有具體世界回應

玩家若情緒不成熟：

* 山本不立即給下一球；
* 名單公布時先限制公開情緒。

玩家若與阿哲疏遠：

* 場上沒有人喊補位；
* 名單公布後阿哲不再靠近。

這證明世界會記住不舒服的選擇，而不是永遠讓人物配合玩家。

---

### 4. 落選仍保有追讀力

高橋在玩家落選時不羞辱，而是指出最好的一球。

山本提醒名單只評價現在。

阿哲則依關係決定是否靠近。

因此落選不是：

> 失敗，請重新開始。

而是：

> 你目前沒有得到位置，但人物已經看見你的某些價值，下一階段仍然成立。

這符合遊戲「不以失敗作為終點，而以追求與可望推動」的核心精神。

---

## 四、第四章目前主要問題

### 問題 1：最終評價如何計算，玩家可能仍看不懂

測驗開始前會顯示：

* 玩家評價；
* 競爭者評價。

這是進步。

但玩家未必知道自己的評價究竟來自：

* 技能；
* 教練信任；
* 比賽表現；
* 人物印象；
* 三次準備行動；
* 疲勞或壓力；
* 最後測驗選項。

如果數值突然高或低，玩家可能感覺結果由隱藏公式決定。

後續 UI 應至少顯示三到四個主要組成，例如：

```text id="crjvym"
守位完成度
教練信任
訓練準備
臨場表現
```

不必公開全部公式，但必須讓玩家能建立因果理解。

---

### 問題 2：最後五球的實際結果差異不足

三個選項的文案明確寫出：

* 穩定；
* 判斷風險；
* 搶眼與失手代價。

但選項效果主要增加屬性、關係、疲勞與壓力，沒有直接顯示：

* 五球完成幾球；
* 哪一球失誤；
* 是否完成關鍵動作；
* 最後評價因此增加多少。

這使最終測試的情緒張力高度依賴結算公式，而不是玩家立即看見的五球過程。

後續可讓選項結果至少顯示一個短小的五球紀錄。

---

### 問題 3：穩定選項可能成為最佳數值答案

穩定路線同時提供：

* 壓力降低；
* 教練信任兩點；
* 技能成長；
* 無疲勞代價。

相較之下：

* 觀察選項增加壓力；
* 進攻選項增加壓力與疲勞。

如果教練信任直接影響最終評價，穩定選項可能明顯優於其他路線。

這會削弱玩家根據球員風格做選擇的意義。

---

### 問題 4：最終先發測試重新合流得太整齊

前半章有非常多人物與關係分支，但最後所有人都進入同一組五球選項。

這有利於維護與結算，但也可能讓玩家感覺：

> 前面雖然見到不同人物，最後真正決定先發的仍是同一題。

較理想的方式不是建立更多完整分支，而是讓人物狀態改變五球測驗中的一個條件：

* 山本高信任：允許玩家自行決定處理方式；
* 山本不成熟印象：第一次失誤後會被暫停；
* 高橋高敬意：高橋先做出高難度示範；
* 阿哲高連結：阿哲提供一次有效喊聲；
* 阿哲疏遠：補位資訊不足；
* 疲勞高：後兩球動作變慢。

這樣前半段關係會真正進入最後測驗，而不只是影響事前評價。

---

### 問題 5：章末結算資訊仍偏抽象

`competition_result` 顯示：

* 目前位置；
* 教練信任；
* 隊友連結；
* 宿敵敬意。

這能看見系統狀態，但還缺少人物弧線的語意名稱，例如：

```text id="27uhfl"
山本：值得交付任務
阿哲：信任，但開始依賴
高橋：承認彼此為競爭者
先發狀態：暫時先發
```

單看數字，玩家不一定理解：

> 六點隊友連結和四點宿敵敬意，在故事裡代表什麼？

---

### 問題 6：捕手路線仍比其他守位完整

一般守位共用測驗，而捕手有專屬場景和關係回應。

這會讓捕手成為目前敘事內容最豐富的守位。

不必刪減捕手，而是後續讓其他守位測驗增加一個專屬人物互動或場上條件。

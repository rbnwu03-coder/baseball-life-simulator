# 三、高卒職業專屬事件

## `transition_pro_roster_window`

### 暫定標題

```text
第一次升降窗口
```

### 核心情境

球團需要為一軍傷兵補上一個名額。

玩家和另一名同期新人都在候選名單中。

同期新人：

* 年紀相同；
* 身體較健康；
* 單一守位能力較明確；
* 不一定比玩家全面，但更容易被教練說明用途。

### 核心問題

> 職業球團不是只比較誰比較強，而是比較現在需要誰。

### 三個選擇方向

#### 1. 接受短期工具人任務

玩家願意：

* 守第二位置；
* 代跑；
* 牛棚接捕；
* 接受不固定打席。

主要價值：

* 增加立即可用性；
* 提高組織角色評價；
* 專精成長變慢。

#### 2. 要求以主守位進行公平比較

玩家希望：

* 用最強工具直接競爭；
* 不因多功能而被固定成替補；
* 接受落選風險。

主要價值：

* 增加主守位評價；
* 增加曝光與壓力；
* 失敗時可能失去這次升降窗口。

#### 3. 主動提出健康與負荷限制

玩家完整說明：

* 疼痛；
* 恢復狀況；
* 可承擔局數；
* 不能承擔的連續使用方式。

主要價值：

* 提高長期信任；
* 降低本次升上一軍機會；
* 降低傷病風險。

### 必須形成的結果差異

| 選擇    | 短期結果      | 長期結果      |
| ----- | --------- | --------- |
| 工具人任務 | 較容易進入短期名單 | 主守位專精下降   |
| 主守位比較 | 有機會改變定位   | 落選代價較高    |
| 健康揭露  | 本次機會下降    | 組織信任與健康提高 |

# 四、大學棒球專屬事件

## `transition_college_eligibility`

### 暫定標題

```text
資格、主力與選秀窗口
```

### 核心情境

全國賽前，球隊主力位置出現空缺。

玩家有機會進入輪替，但某門課的缺席與成績已接近資格警戒線。

這不是普通的時間管理，而是：

> 參加額外訓練，可能取得主力；繼續缺課，可能失去正式比賽資格。

### 核心問題

> 大學提供更多成長時間，但這段時間有學籍與資格條件。

### 三個選擇方向

#### 1. 先處理資格，再爭取輪替

玩家和教授、助教及教練協調補課。

主要價值：

* 保住比賽資格；
* 降低短期訓練量；
* 建立責任與自主管理能力。

#### 2. 先搶下主力，再處理學業

玩家把全國賽視為稀有市場窗口。

主要價值：

* 增加曝光；
* 增加近期表現機會；
* 學業與倦怠風險升高。

#### 3. 放棄這次主力競爭，延長發展時間

玩家承認目前身體、課業與能力無法同時承擔。

主要價值：

* 降低疲勞與傷病；
* 保住長期發展；
* 錯過一次公開舞台。

### 必須形成的結果差異

| 選擇   | 短期結果     | 長期結果      |
| ---- | -------- | --------- |
| 保資格  | 上場順位成長較慢 | 保住學籍與後續窗口 |
| 搶主力  | 曝光與表現提高  | 資格與倦怠惡化   |
| 延後競爭 | 錯過本次大賽   | 身體與長期成長提高 |

# 五、業餘／社會人專屬事件

## `transition_amateur_company_conflict`

### 暫定標題

```text
公司要你留下，球隊也要你報到
```

### 核心情境

公司遇到重要專案，需要全組加班。

同一天，球隊要進行都市對抗賽最後名單測試。

主管並不是反對棒球；教練也不是不理解工作。

問題是兩邊都真的需要玩家。

### 核心問題

> 社會人球員不是在夢想與現實之間二選一，而是在兩個真實責任間分配信用。

### 三個選擇方向

#### 1. 和主管談交換班與明確期限

玩家提出：

* 提前完成工作；
* 和同事交換；
* 比賽後補回時間；
* 不把問題丟給其他人。

主要價值：

* 同時保住部分工作與棒球信用；
* 增加疲勞；
* 考驗責任與協調。

#### 2. 留在公司完成專案

玩家錯過名單測試。

主要價值：

* 財務與工作信任提高；
* 棒球曝光下降；
* 球隊可能重新分配位置。

#### 3. 直接請假參加測試

玩家把稀有棒球機會放在第一位。

主要價值：

* 增加曝光與近期表現；
* 收入與主管信任下降；
* 未來排班更困難。

### 必須形成的結果差異

| 選擇   | 短期結果      | 長期結果      |
| ---- | --------- | --------- |
| 協商交換 | 兩邊都保留部分信用 | 疲勞與人情成本增加 |
| 工作優先 | 生活穩定      | 球隊順位下降    |
| 棒球優先 | 獲得測試機會    | 收入與職場信用下降 |

# 六、復健路線專屬事件

## `transition_rehab_reentry_deadline`

### 暫定標題

```text
測試邀請只保留到月底
```

### 核心情境

一支業餘隊願意讓玩家參加月底測試。

醫療評估顯示：

* 日常動作已恢復；
* 高速傳球仍未完全穩定；
* 再多六至八週，恢復可能更完整；
* 但球隊不保證之後仍有名額。

### 核心問題

> 復健不是等到百分之百才回去，而是決定自己願意在什麼恢復程度承擔重新競爭的風險。

### 三個選擇方向

#### 1. 接受月底測試，但限制任務

玩家只參加：

* 低負荷守備；
* 指定局數；
* 有限打席；
* 不做最大強度傳球。

主要價值：

* 保留重新進入球隊的機會；
* 市場會看見健康限制；
* 復發風險中等。

#### 2. 放棄這次測試，完成復健

玩家不讓名額期限取代醫療進度。

主要價值：

* 恢復與健康提高；
* 曝光和球隊歸屬繼續下降；
* 可能需要自己尋找下一次測試。

#### 3. 不限制強度，測試自己還剩多少

玩家希望用一次完整測試取得明確答案。

主要價值：

* 有機會重新獲得球員定位；
* 曝光提高；
* 復發與疼痛風險最高。

### 必須形成的結果差異

| 選擇     | 短期結果     | 長期結果      |
| ------ | -------- | --------- |
| 限制任務參測 | 保留名額可能   | 被標記為負荷受限  |
| 完成復健   | 錯過本次測試   | 恢復與長期健康提高 |
| 全力測試   | 可能快速重返球隊 | 復發風險最高    |

# 七、保留的共同事件

四條道路完成第三個專屬事件後，仍共同進入：

```text
transition_relationship
transition_cost_check
```

## 保留 `transition_relationship` 的理由

四條道路雖然生活不同，但都需要回答：

> 現在還喜歡棒球嗎？

這是從第一章一路延續到成年的共同問題。

## 保留 `transition_cost_check` 的理由

四條道路都需要面對：

> 已經選下去的生活開始收取什麼代價？

事件文字可以依道路不同，但核心選擇仍可共用：

* 接受代價；
* 縮小短期目標；
* 設定期限取得答案。
